Что остаётся до закрытия цикла

  1. Закрыть native Slice 0 независимо

    Проверить собранный CLI извне: поток до завершения модели, реальные тексты/EntryId после restart, повторные ответы и корректный shutdown. Артефакт уже готов; source-review идёт.

  2. Довести тестовую миграцию

    Первый пакет перенесён и проверен: 41 adapter cases без падений. Остальные старые импорты не объявлены починенными; это остаток Task 1, а не отложенная потеря покрытия.

  3. Перепроверить исправленный dispatcher и guards

    Source GREEN у dispatcher не заменяет повторный compiled-run. У AST-checker переоткрыт настоящий false-green: произвольный main, отсутствующий экспорт и поддельный runner-путь проходят проверку.

  4. Замкнуть оставшиеся рабочие возможности

    Host tool round-trip, bindings/fork/tools registration, probe без сессии, корректные metrics, abort → новый prompt и отсутствие разделяемых globals.

  5. Принять один целый кандидат

    Свежий build + отдельный typecheck + полный regression suite + native product/architecture review. Без этого не объявляем Cycle 7 готовым и не делаем release/deploy.
