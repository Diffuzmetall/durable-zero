Главные границы ответственности
  • core — правила и порты; никакого SDK, storage или host RPC.
  • runner — одна сборка адаптеров и одна клиентская граница.
  • PiDurableEngine — адаптация существующего native runtime, не новый agent loop.
  • Harness — выполнение и durable state; транспорт — wire IDs и ожидания.
  • HostBridge — reverse вызовы и payload validation, без второго RPC-трекера.
