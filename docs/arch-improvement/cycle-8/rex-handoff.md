
Runtime работает отдельным процессом. Его PID записан в `runtime.pid` внутри новой папки сессии. `/detach` и закрытие терминала не останавливают runtime.

Основная команда `pi-durable`, прежний сервис и существующие пользовательские сессии не переключены. Учётные данные не копировались в сборку. Сессии старой установки не мигрировали.

## Повторное подключение

В обычном shell-терминале, не в редакторе Pi:

```sh
PREFIX=/home/ubuntu/.local/share/pi-durable-zero/candidates/20261105T2146-standalone
SESSION=/home/ubuntu/.local/share/pi-durable-zero/test-sessions/rex-20261105T2146
node "$PREFIX/bin/terminal.mjs" --session-dir "$SESSION"
```

Для остановки тестового runtime сначала сверить PID и команду процесса. Затем останавливать только этот процесс. Удалять сессию или менять основную установку для отката не требуется.
